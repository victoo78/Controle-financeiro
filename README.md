# Controle Financeiro

Aplicacao web de controle financeiro pessoal desenvolvida com React. Permite registrar e acompanhar entradas e saidas financeiras de forma simples e intuitiva.

---

## Tecnologias utilizadas

- [React](https://reactjs.org/) — biblioteca principal para construcao da interface
- [Create React App](https://github.com/facebook/create-react-app) — configuracao inicial do projeto
- JavaScript (ES6+)
- HTML5 / CSS3

---

## Pre-requisitos

Antes de rodar o projeto, certifique-se de ter instalado:

- [Node.js](https://nodejs.org/) (versao 14 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

---

## Como rodar o projeto

Clone o repositorio:

```bash
git clone https://github.com/victoo78/Controle-financeiro.git
cd Controle-financeiro
```

Instale as dependencias:

```bash
npm install
# ou
yarn install
```

Inicie o servidor de desenvolvimento:

```bash
npm start
# ou
yarn start
```

Abra [http://localhost:3000](http://localhost:3000) no navegador para visualizar a aplicacao.

---

## Scripts disponiveis

| Comando | Descricao |
|--------|-----------|
| `npm start` | Inicia a aplicacao em modo de desenvolvimento |
| `npm test` | Executa os testes em modo interativo |
| `npm run build` | Gera a versao otimizada para producao na pasta `build` |
| `npm run eject` | Expoe as configuracoes internas do Create React App (irreversivel) |
